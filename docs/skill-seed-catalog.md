## 维护规则

- 任何条目必须有 `repository`、`githubUrl`、`lastVerifiedAt`、`requirements`、`permissions`、`prompt`。
- 不得出现“安装量/真实用户数/安全保证”这类无法核验的字段。
- 任何风险较高（联网、脚本、文件覆盖、写入云端）的条目都必须在详情页强调权限边界。
- 源码变更后先跑 `npm run check:skills`，再更新本日志中的时间和变更说明。
